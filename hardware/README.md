# Hardware

## Parts

- ESP32 dev board (with Bluetooth Classic — e.g. ESP32-WROOM-32). Note: the
  ESP32-S2/S3 and C3 do **not** have Bluetooth Classic, which the Wii remote
  needs. Use a classic ESP32.
- Nintendo Wii remote.
- USB cable + 5V power for the ESP32.
- WiFi network shared by the ESP32 and the TouchDesigner computer.

## Notes

- Pair the Wii remote by pressing **1 + 2** (or the red sync button) while the
  ESP32 is booting / waiting.
- Document any additional wiring (LEDs, buttons, sensors) and pin assignments
  here as the build progresses.
